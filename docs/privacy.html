Privacy Policy

Daily Review Uploader. Last updated: 12 November 2026.

What this app is

Daily Review Uploader is a personal tool, used only by the owner of the YouTube channel Daily Review My Portfolio. It uploads the owner's own videos to the owner's own YouTube channel through the YouTube API Services. It is not offered to other users.

Data the app accesses

The app asks for one permission on the owner's Google account: youtube.upload, which lets it upload videos to the owner's YouTube channel. It does not read the owner's email, contacts, files, or watch history, and it does not access any other person's account.

How data is used and stored

  • The app uploads only video files and the title and description text that the owner supplies.
  • The authorization token that lets the app upload is stored as a private secret in the owner's own GitHub repository settings. It is not shared with anyone.
  • The app does not collect, sell, share, or transfer personal data to any third party, and does not use it for advertising.

YouTube API Services

This app uses YouTube API Services. By using it, the owner agrees to be bound by the YouTube Terms of Service. Google's use of information is described in the Google Privacy Policy.

Revoking access

The owner can revoke the app's access to the Google account at any time at https://security.google.com/settings/security/permissions.

Contact

Questions can be sent through the Instagram account @portfolio.daily.
